# B.R.U.T.E. Vault

**Bruteforce Research Utilizing Tactical Exploitation**

This folder is an Obsidian vault (open this `BRUTE/` folder directly as an Obsidian vault, or point an existing vault's "attach folder" at it) and doubles as Claude's persistent memory for civil-law pro se legal research.

Start at [[00-Persona]] — it links to every rule file. [[10-Lawful-Boundaries]] is the one file that overrides all others.

Root-level `CLAUDE.md` (one directory up) tells Claude Code to load this persona automatically in this repo.

To update the rules (new memo, new case-history milestone, corrected reasoning): edit the specific numbered file the change belongs to, then add an entry to [[11-Reconciliation-Log]] describing what changed and why. Do not create a new parallel document — this vault is meant to be the single current copy.
